# 17. Testing your game

Besides playing it, a game can be **driven by a script**: the game runner presses keys, clicks,
waits, takes screenshots and prints its state. That is how the editor's AI agents play-test
(`play_test`, [chapter 13](13-ai-agents.md)), and how you can check that a quest still works after
a change without playing it through by hand. From a terminal:

```sh
RUSTPG2D_AUTOPLAY="wait 1; talkto tilda; wait 3; status; shot /tmp/tilda.png; quit" \
  rustpg2d-game path/to/project --no-title --map shop --spawn entrance
```

`--no-title` skips the title screen; `--map` / `--spawn` (or `--pos X,Y` in pixels) start
somewhere specific; `--dev` adds the developer console and live script reloading
(play-tests from the editor use it). A crafted save in `saves/quick.ron` loaded with `press f9`
starts in a precise situation (loading never fires *Map enter* triggers).

## How a script runs

The game runner plays a script when it is started with `RUSTPG2D_AUTOPLAY="cmd; cmd; …"` —
the editor's play-tests from agents (`play_test`) and the project's own test runs use it. Commands
are separated by `;`, words by spaces; they run in order, each `wait` and `hold` taking its time,
everything else one frame. Output goes to stdout: `[autoplay] …` lines from `status`, the game's
own `[game]` / `[events]` messages, and `error:` lines.

## Commands

| Command | Does |
|---|---|
| `wait SECS` | Waits (dialog text types out over ~2.5 s; wait before reading it). |
| `press KEY[+KEY]` | Presses keys for one frame: letters, `enter`, `escape`, `space`, `tab`, `up` `down` `left` `right`, `f1`…`f12`, `shift+g` (Shift held). `e` interacts / confirms (first press completes a dialog page's text, the second closes it), `escape` opens the pause menu, `c`/`i` the character window, `k` skills, `l` spells, `m` the map, `h` hides the HUD, `x` attacks, `f5` quick-saves, `f9` quick-loads, `q` swaps weapons. |
| `hold KEY SECS` | Holds keys (movement: `hold right 0.5` walks about one tile per 0.2 s). |
| `keydown KEY[+KEY]` / `keyup [KEY]` | Holds keys while the next commands run (`keydown f; wait 0.3; shot …; keyup`); `keyup` without a key lets go of all. |
| `pad BUTTON[+BUTTON]` / `padhold BUTTON SECS` | Gamepad: `a b x y lb rb lt rt select start ls rs up down left right`. |
| `click X Y` / `rclick X Y` | Left / right click on tile (X, Y) of the map; right-click walks there. |
| `rhold X Y SECS` | Right-click tile (X, Y) and keep the button down for SECS seconds (*Hold to repeat* on a tree or a rock). |
| `clickenemy` | Clicks the nearest enemy. |
| `type TEXT` | Types text (the character creator's name field). |
| `hud window\|map` | Clicks the HUD's character-window or map button. |
| `wintab character\|sheet\|spells` | A tab of the open character window (`skills` = `sheet`; also `graphics`, `sound`, `gameplay`, `accessibility` on the Options page, and the journal's tabs). |
| `slot N` / `slotdrag A B` / `slotdrag player N out` | Inventory slots: use / move / drop. |
| `bar ENTRY` / `barpick K` | The action bar outside fights: activate an entry (`use`, `cast`, `class`, `search`, `rest`, `sneak`, `party`, a custom entry's function), pick row K of the open list. `press f` / `pad rb` focus the bar. |
| `shop buy\|sell N` | Row N of the open shop. |
| `opt ROW prev\|next\|row` | The Options page's arrows. |
| `minigame bite` | Press E when a fish bites (the fishing game; the lockpicking game of 0.27 and older became a DEX check). |
| `waitturn [SECS]` | Waits (at most SECS, default 30) until it is the hero's turn in a fight, ready to act: nothing walking on screen, no Kill / Knock out question open. Fast AI turns (`turn fast on`) take varying time; this keeps a script in step. |
| `craft K` | The Make button of recipe row K in the open crafting window. |
| `mapbtn close\|zoomin\|zoomout\|center` | Buttons of the map screen. |
| `drag X1 Y1 X2 Y2` / `wheel DY` | Mouse drag / wheel in screen pixels (the map screen). |
| `console LINE` | A developer console line (the game runs with `--dev` in play-tests): `call FN`, `give ITEM N`, `take ITEM N`, `money CP`, `pay CP` (*Give money* / *Take money* in copper pieces), `charges ITEM N` (a magic item's charges left), `flag NAME on\|off`, `var NAME V`, `settime H`, `teleport MAP SPAWN`, `hp N`, `xp N`, `reload`, or any Rhai expression. |
| `settime H` / `settime +H` | Sets the clock / lets H hours pass (days pass, props regrow). |
| `seed N` / `learn ID` / `cast ID` / `call FN` | Make the SRD dice roll the same from here on (also `RUSTPG2D_SEED=N`; automated runs start with seed 1), learn / cast a spell, call a script function. |
| `crit always\|never\|chance` | The hits of the player's side in fights: always critical, never, or by the dice again. |
| `attune ITEM` / `unattune ITEM` | The hero attunes to a magic item they carry (an hour passes; outside fights, at most three) / ends it; prints `[autoplay] attune ITEM: ok` or why not. *(0.31)* |
| `use ITEM` / `equip ITEM` | Uses an item from the bag as a double-click does (a potion's effect, a wand's spell: its Cast window in a fight; gear is put on) / puts a worn or held item on (a ring into a free ring slot); prints `ok` or why not. *(0.31)* |
| `turn …` | Plays the current turn of a fight (prints `[turn] LINE: ok` or why not): `turn move X Y` (walk to a reachable tile), `turn attack NAME [strike|throw]` (attack, walking into reach first; `throw` throws a weapon that can be thrown, as *Attack › Throw*), `turn action cast|class|attack` (opens the choice window), `turn menu` (its rows: `cast[>0:Fire Bolt | 1:Fireball!No spell slot left]`, `>` selected, `!` greyed with why), `turn pick K` (picks row K), `turn action dash\|disengage\|dodge\|hide\|search`, `turn action ready` (the Ready window: the attack or a spell, then `turn pick K`), `turn help\|grapple\|offhand NAME` (`help` on a fallen ally: first aid; `grapple` on the one it holds: lets go), `turn release` (lets go of the creature it grapples), `turn shove NAME prone\|push`, `turn cast SPELL [NAME | X Y] [slot N]` (a spell at a fighter or a tile, at a slot level; without a target at the cursor's aim), `turn aim SPELL [slot N] [X Y]` (aims it and puts the cursor on the tile: the area shows, for screenshots), `turn class ACT [NAME]` (a class action by its id: `rage`, `second-wind`, `action-surge`, `flurry-of-blows`, `lay-on-hands finn`…; without NAME on the hero, the nearest foe or the most hurt ally it fits), `turn use ITEM`, `turn end`, `turn log [N]` (the fight log's last N lines, default 8), `turn specs` (the hero's attacks as a fight rolls them, also outside fights: `Longsword:+4:1d10+2:melee1`, `:finesse`, `:dis`, `ranged16/64`); `turn ai NAME on\|off` (who plays a companion's turns), `turn fast [off]` (the AI's turns without pauses), `turn start` (the *Start fight* action). NAME is what `combat=` prints (several of a name: the nearest to whose turn it is). |
| `levelup [FEATURE VALUE[,VALUE] …]` | Makes the choices of the first waiting level-up (the hero's or a party member's) and closes it (prints `[levelup] LINE: WHO:LEVEL {picks}`): `levelup subclass champion`, `levelup fighter-fighting-style fighter-fighting-style-defense`, `levelup rogue-expertise-1 stealth,thieves-tools`, `levelup fighter-ability-score-improvement-1 ability:str,ability:dex` (or `feat:grappler`). Alone it takes the first options; picks for features of another level or values not offered are left out (listed as *not offered*). The status field `levelup=` shows what waits. |
| `spawners` | Prints the spawner zones' state. |
| `close` | The open window's close button. |
| `talkto NAME` | Right-clicks the character named NAME where it stands now: the player walks there and talks (characters that wander). |
| `status` | Prints one `[autoplay]` line with the game state (below). |
| `shot NAME` | A PNG screenshot (play_test returns it as an image). |
| `quit` | Ends the run (play_test appends it). |

A fresh game starts with the title screen unless `--no-title` (play_test's default): then it
begins on the chosen map and spawn, with the map's *Map enter* triggers and cut-scenes
(`cutscene=` in `status` while one plays; `press e` advances its dialogs).

`statblocks=`: the characters within 8 tiles that have an SRD stat block, the definition id when unnamed and `-` for a block made by hand, `class-ranger` for a party member's block from its class; `class=`: the hero's class, subclass and level, then in brackets the party members on the map with a class; `resources=`: the class resources of the hero (`player`) and the party members on the map, their uses left of the most (`player:rage:2/3`); `class_fx=`: what class features keep going in a fight: rounds of rage left, a frenzy, Reckless Attack, a Bardic Inspiration die held, Sacred Weapon's rounds, temporary hit points; `attuned=`: the magic items the hero is attuned to; `charges=`: the hero's magic items with charges, the charges left on the fullest stack of the most; `ammo=`: the stack in the Ammunition slot (`-` = empty), then with a ranged weapon in hand what its next shot takes and how many are left there (`slot` or `bag`), `>none` when it has none; `sight=`: each foe in the fight as the hero sees it, with why when not clearly (`dark`, `dim`, `fog`, `foliage`, `invisible`, `blind`); `knocked_out=`: the characters fights knocked out instead of killing them (the name, else the definition id, and the map); `levelup=`: the level-ups waiting for their choices (`player:4`, a party member by name: `finn:3`), `(open)` while the window shows the first; `creator=` while the creator is open ends with `pN METHOD base … total … picks[…] bg:…`, page 2's state) (`rolls=`: the last six SRD rolls, oldest first: a check or saving throw as `what:total/DC:ok|fail` with `:nat20` / `:nat1` when the d20 showed it, a dice roll as `dice:total`; `abilities=` the hero's six scores, `prof=` the proficiency bonus, `profs=` the hero's proficiencies) (`factions=`: the player's faction and standing with every faction of the project, then in braces the characters on the map whose faction isn't their definition's (`*` = changed in play by *Set faction*), `-` without factions; `foes=` lists the characters hostile to the player)

The useful fields for checking content: `map` and `tile` (where the player is), `dialog` (a
dialog is open), `cutscene`, `quests` (quest id → stage), `inv`, `flags`, `vars`, `hp`,
`props` (props not in their first state), `npcs` (characters on the map and their gear),
`enemies`, `menu` (`defeated` after a death), `autosave`, `schedule` (scheduled characters:
name:stop-time[>map](walking|inside|elsewhere)[:sit|:lie]@x,y), `sounds` (the last six sound
effects started, also when the game is muted: a bell or an animal's call), `climbing` (the
player is on a ladder: `true`, `true:dc12` on a climbable wall with a check, `false`), `fall` (the last fall's
height and damage, `20ft:7`, `-` without one; `:jump` while the hero is in the air), `survival` (food and water eaten and drunk today, the days without food and the hours of the march: `food:1.00 water:0.50 unfed:0 march:3.2h`, the parts whose rule is on; `-` with both off), `load` (pounds carried / capacity, `:encumbered`, `:heavy`, `:dragging` or `:over` when it slows the hero), `bar` (the action bar: `fight`, or `explore[use,cast,…]` with `:focus=ENTRY` and `:open=ENTRY[>0:Potion|1:Fire Bolt!Only in a fight]`: the open list's rows, `>` selected, `!why` greyed), `search` (the total of the last search, `-` before one), `objects` (damaged or broken props with object statistics: `name:hp/max@x,y`), `traps` (the trap zones and trapped props on the map: `name:armed|found|disarmed|sprung@x,y`, unnamed ones by their uid), `coating` (the poison on the hero's weapon or ammunition: `POISON>ITEM:SECONDSs`, without seconds when it lasts until delivered; `-` without), `diseases` (the hero's diseases: `id:onset@HOURS` incubating, `id:sick:DC/STAGE/-HP` sick; `-` without), `monster_fx` (the fighters with special abilities: `name:spent(Fire_Breath):legendary3:resist2:regen[:down][:stopped]`; `-` outside fights), `react` (the reactions the Reaction window asks for now, `shield|pass`, `protection|pass`; `-` when it is closed; `turn pick K` answers it, also on others' turns), `shape` (the hero's beast shape, `player>wolf:11/11:7199s`, and characters' `orc>owl:1/1`; `-` without; `turn pick K` / `barpick K` choose the beast in the window), `detect` (what the hero's Detect Magic / Poison / Evil and Good senses within 30 ft, `[locked_chest@16,33]`; `-` without such a boon), `areas` (lasting spell areas, `spirit-guardians:49:600s` = the spell, its tiles, seconds left; `-` without), `summons` (summoned creatures, `dire-wolf:37/37:3600s`, `owl:1/1:-` without a time limit; `-` without), `senses` (the light at the hero for checks by sight, `light:bright|dim|dark`, `:darkvision`; then who of the party helps with which skill, `help:survival=Fisher`, `help:-`; then the hero's special senses from spells and items, `see:truesight120,see_invisibility`), `foes` (the hostile characters on the map with their HP and tile:
whether a shot hit), `device` (the device used last: hints show keys or pad buttons; `pad a`
switches to the pad, `press` or a click back), `pad_style` (how buttons are drawn), `combat` (the fight going on: whose turn, the movement and
action left, the turn order with hit points) and `death_saves` (who is down at 0 HP and how their
death saving throws stand), `emotes` (emotions shown over heads now; `player:joy`), `ground` (the painted material under the
player's feet and how many materials the map uses: `sand/9`, `-/0` without painted ground).

For performance checks: `fps`, `frame_ms` (average / worst frame), `update_ms` and `draw_ms`
(average time of the two halves of a frame) and `astar` (path searches and the nodes they
expanded), all since the previous `status`, so `wait 10; status` measures ten seconds. With
`RUSTPG2D_PERF=1` the game also logs the same as a `[perf] … entities=N` line every second.

## Tips for play-tests

- Park the mouse first (`drag 2 2 2 2`), or the real pointer over the window moves the menu
  selection.
- Talk to a character: stand next to them facing them (`hold right 0.3`), `press e`, `wait 2.5`,
  `press e` (completes the text), `wait 0.5`, `press e` (closes), then `status`.
- A `Choice`: `press down` / `press up` select, `press e` confirms.
- Start at a precise tile with `pos` (play_test) instead of walking there.
- Keep runs short (`timeout_secs`): the game window is on the person's screen meanwhile.
